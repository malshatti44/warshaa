Retoush portable mode

While this file sits next to retoush.exe, Retoush keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the RetoushData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Retoush with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Retoush) instead.
If RetoushData can't be written (for example on a read-only drive), Retoush says so and
uses %APPDATA%\Retoush instead.
