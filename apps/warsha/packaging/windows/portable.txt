Warsha portable mode

While this file sits next to warsha.exe, Warsha keeps its settings, its
download cache and its record of installed apps in the WarshaLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Warsha with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Warsha) instead.
If WarshaLauncherData can't be written (for example on a read-only drive), Warsha says
so and uses %APPDATA%\Warsha instead.
