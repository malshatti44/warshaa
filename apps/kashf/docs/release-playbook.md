# Release playbook

The release playbook shared by every warsha app lives in warsharules:
[`../warsharules/release/playbook.md`](../../../warsharules/release/playbook.md)
(`malshatti44/warshaa`, `release/playbook.md`). It is the canonical copy; don't duplicate it
here. The signing runbook is next to it in `release/signing-setup.md`.

Kashf's copy was taken from Nasaq (`.github/workflows/release.yml`, `packaging/`,
`cargo xtask version`). Kashf-specific details are in [releasing.md](releasing.md).
