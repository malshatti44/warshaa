## ما هي ورشة؟

ورشة مجموعة من **اثني عشر تطبيقًا** بواجهة عربية كاملة من اليمين إلى اليسار (مع الإنجليزية)، تعمل **دون إنترنت** على **ويندوز وماك ولينكس**. يمكنك تنزيل **مكتبة ورشة** الكاملة وتثبيت ما تحتاجه منها بضغطة زر — مثل Adobe Creative Cloud — أو تنزيل أي تطبيق بشكل مستقل.

## التنزيل والتثبيت

حمّل الملفات من صفحة **[الإصدارات (Releases)](https://github.com/malshatti44/warshaa/releases)**:

| النظام | الملف |
|---|---|
| ويندوز 10/11 | `Warsha-Setup-…-win-x64.exe` (أو مثبّت التطبيق المستقل مثل `Satr-Setup-…exe`) |
| ماك Apple Silicon (M1–M4) | `…-mac-arm64.dmg` |
| ماك Intel | `…-mac-x64.dmg` |
| لينكس | `….AppImage` أو `….deb` |

> **ملاحظة:** المثبّتات غير موقّعة رقميًا حاليًا، لذلك قد يظهر تحذير عند أول تشغيل:
> - **ويندوز:** في رسالة «Windows protected your PC» اضغط **More info** ثم **Run anyway**.
> - **ماك:** اسحب التطبيق إلى مجلد Applications ثم انقر عليه بزر الفأرة الأيمن ← **Open**. إن ظهرت رسالة أن التطبيق «تالف» نفّذ: `xattr -cr "/Applications/Warsha.app"`
> - **لينكس:** `chmod +x Warsha-*.AppImage` ثم شغّله، أو `sudo apt install ./Warsha_*.deb`

### مكتبة ورشة
بعد تثبيت **Warsha** تفتح المكتبة التي تعرض جميع التطبيقات؛ اضغط **تثبيت** لإضافة اختصار التطبيق إلى سطح المكتب وقائمة البرامج، أو **تثبيت الكل**، ويمكنك فتح أي تطبيق مباشرة منها.

## مزايا عامة
- واجهة عربية أصيلة من اليمين إلى اليسار، مع التبديل إلى الإنجليزية في أي وقت.
- 13 خطًا عربيًا مدمجًا (القاهرة، تجوال، أميري، المراعي، رقعة، كوفي…) تعمل دون إنترنت.
- سمة داكنة وفاتحة، واختصارات لوحة مفاتيح معروضة في القوائم.
- فتح الملفات بالنقر المزدوج من نظام التشغيل، والملفات الأخيرة، والسحب والإفلات.

## للمطورين

```bash
npm install            # تثبيت Electron و electron-builder
npm start              # تشغيل مكتبة ورشة
npx electron . --app=satr   # تشغيل تطبيق محدد
node scripts/web-test.js all # اختبار كل الواجهات في Chromium (Playwright)
node scripts/build.js satr --win   # بناء مثبّت تطبيق واحد (hub | all | <id>)
```

البنية:
- `src/shared/` إطار العمل المشترك (الواجهة، الترجمة، الملفات، الخطوط، المكتبات).
- `src/apps/<id>/` كل تطبيق في مجلده، دون خطوة بناء.
- `src/hub/` مكتبة ورشة.
- `src/main/` عملية Electron الرئيسية والجسر الآمن.
- `.github/workflows/build.yml` اختبار دخان لكل التطبيقات في Electron، وبناء المثبّتات لكل الأنظمة ونشر الإصدارات.

### English

**WARSHA** is a suite of 12 offline creative apps (photo editing, vector design, video editing, photo developing, PDF tools, social design, page layout, word processing, presentations, spreadsheets, 2D CAD and audio editing) with a native Arabic right‑to‑left interface and English, for Windows, macOS and Linux. Download the **Warsha** library to install any app with one click, or download each app on its own from the [Releases](https://github.com/malshatti44/warshaa/releases) page.
